# Phramacum

Phramacum is a lightweight front-end demo app inspired by a drug misuse intelligence dashboard.

## Features

- Sidebar navigation between dashboard modules.
- Dynamic KPI cards and alert banner.
- Refresh simulation to randomize metrics.
- Reports module with severity filter.
- Hotspot, trend analytics, notes, and citations sections.

## Run locally

Because this is a static app, you can open `index.html` directly or run a quick web server:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
